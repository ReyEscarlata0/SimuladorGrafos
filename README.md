# SimuladorGrafos

Visual simulator for graph algorithms built with **C#** and **WPF**. It lets you create graphs and watch classic algorithms run step by step.

## Features

- Interactive graph creation (vertices and weighted edges)
- Step-by-step visualization of graph algorithms:
  - **Dijkstra** – shortest paths from a source vertex
  - **Prim** – minimum spanning tree
  - **Kruskal** – minimum spanning tree
- Desktop interface built with WPF (XAML + value converters)

## Tech Stack

- C#
- WPF (.NET)
- XAML

## How to Run

1. Clone the repository:
```bash
   git clone https://github.com/ReyEscarlata0/SimuladorGrafos.git
```
2. Open `SimuladorGrafos.slnx` in a recent version of Visual Studio 2022 (with the .NET desktop development workload).
3. Build and run the project (F5).
